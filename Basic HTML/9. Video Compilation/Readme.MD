# Robotics Academy Video Hub

A curated video platform showcasing robotics education content from our academy, including YouTube tutorials and Instagram student projects.

---

## Features

- Embedded YouTube robotics tutorials
- Instagram student project showcases
- Clean, responsive layout
- Dark theme UI
- Educational structure (sections per topic)

---

## Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)
- Instagram Embed API
- YouTube Embed

## 📸 Instagram Integration

To add your own Instagram videos:

1. Copy the Instagram reel/post URL
2. Replace this line:

```html
data-instgrm-permalink="https://www.instagram.com/reel/XXXXXXXXXXX/"
```
