v# 🎥 Iframe Video Display

A simple and clean web project demonstrating how to embed a YouTube video using the HTML `<iframe>` element.

Built with HTML, CSS, and JavaScript following modern frontend best practices.

---

## Features

- Embedded YouTube video using iframe
- Responsive and centered layout
- Clean UI with modern styling
- Accessibility-friendly attributes
- Modular file structure

---

## Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)

## Key Concepts Covered

- HTML iframe embedding
- Replaced elements behavior
- iframe security attributes:
  - `allow`
  - `referrerpolicy`
  - `allowfullscreen`
- Basic UI layout with Flexbox
- Separation of concerns (HTML/CSS/JS)
